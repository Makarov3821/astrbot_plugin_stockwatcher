# 个人助理设置与分步引导设计

状态：第 04 步基础能力已实现，命令见 [操作说明](./USAGE.md)。本文保留完整产品目标；当前用明确指令收集草稿，不因完成引导自动订阅，尚无自然语言解析或独立的大盘预期到期提醒。监控需另行显式开启。市场顺序：美股、后续港股与 A 股。

## 1. 已确认的产品要求

- 只服务一个人，使用者即配置者。维护一份个人档案和默认投资组合，不提供注册、角色、成员管理、共享组合或多用户隔离流程。
- 用户可提前指定交易策略和对大盘的预估。
- 提供默认策略，每只股票可设置不同的预期与策略参数。
- 安装后或用户未设置就开始使用时，逐步引导完成必要设置。
- 设置过程解释选择对后续建议的影响，不要求用户先理解技术指标。
- 用户可主动依赖 AI 对持有逻辑、目标价和入场时机的研判。引导区分“个人目标”“愿意承受的过程回撤”和“AI 调整建议”，具体见 [AI 决策辅助设计](./DECISION_SUPPORT.md)。

## 2. 统一个人设置与继承

运行设置：行情来源、模型选择和巡检频率，在 AstrBot 插件配置页提供入口；凭证使用适合保存凭证的配置位置。安装阶段提供“完成配置后发送 /盯盘 开始”的入口；没有会话时不假设安装钩子能直接开展对话。

投资偏好：市场、币种、账户类型、交易周期、默认策略、风险限制和通知偏好。安装配置、聊天指令和分步引导读写同一份个人设置，已经完成的项目直接跳过，不按入口建立不同副本。

市场预期：按市场和参考基准保存，可有不同期限。美股判断不自动用于港股或 A 股。

个股配置：持有/关注理由、预期周期、目标区间、策略选择、加减仓偏好及退出条件；未覆盖的字段动态继承账户默认值。

继承按字段处理：个股显式设置优先于个人默认设置，最后使用已展示的默认模板。未设置、继承、关闭和数值 0 不能混为一谈；支持恢复继承。组合总风险与券商账户的实际交易限制仍构成外层约束，个股设置不能突破。此处的账户限制指现金、交收、购买力等交易条件，不是产品角色权限。

每次分析保存最终解析后的设置快照、模板版本与来源，便于解释和复现。升级默认模板不静默改变已确认的行为参数，应展示差异再应用。

## 3. 首次使用向导

### 第一步：市场和账户

默认展示美股/USD，可选择确认。询问现金或保证金账户，允许暂时未知；未知时标记交易权限未核实，不输出声称可直接执行的精确购买力。涉及金额计算时再收集资产与现金，基本行情查询无需这些信息。

### 第二步：交易风格与持有周期

展示默认日线趋势模板及其行为说明，例如依据完整日线判断、盘中监测已定义条件。用户选择大致持有周期、加仓意愿及退出方式，再映射为模板支持的参数。

产品可解释趋势波段、长期持有等不同需求，但首版只提供已实现的模板；不支持的策略明确提示仅保存为备注或留待适配，不能假装已经能够执行。

### 第三步：风险范围

引导选择组合风险范围、单股仓位上限、是否允许加仓及相应限额。展示可编辑的参数方案与含义，由用户明确采用，不把未答复当作接受。

选择“暂时跳过”后仍可查行情、录入持仓、看趋势说明；缺少所需风险参数时暂停个性化加仓/退出动作建议，提供条件观察与设置入口。缺少现金和资产时不计算精确股数或权重。技术性数据异常与账户权限检查始终有效。

### 第四步：大盘预期

收集用户判断，例如偏多、中性、偏空或暂不判断，并同时记录：

- 适用市场与参考基准。
- 预期持续多久及复核日期。
- 判断理由和可选失效条件。
- 希望如何影响策略：仅作为报告背景，或使用已支持的风险收缩/扩张规则。

默认提供“暂不判断，不施加方向偏好”，明确显示并允许选择。看多不自动提高仓位，也不自动关闭退出规则；只有用户选择了受支持的映射规则才影响动作。

到期后保留历史记录，停止应用过期方向偏好，并合并发送一次复核提示；继续依靠有效策略和行情分析，不自动续期或替用户改成新的观点。

### 第五步：持仓与关注标的

先选择已有持仓或仅关注。已有持仓收集期初数量和成本等账本信息；关注池不强制填写持仓信息。展示账户设置摘要，提供“继承默认”与“单独设置”。

个股自动归入默认投资组合，只需明确持仓或关注状态；其他内容按需求补齐：

- 为什么持有或关注。
- 期待的持有周期、目标价/区间（可空）及其有效期。
- 到达目标前能接受的过程波动或回撤范围，以及是否区分长期底仓与可调整部分；均可暂不设置，底仓/机动仓拆分非首版必填项。
- 是否希望 AI 复核目标、主动提出调整；建议与当前目标分别展示，采用后才更新。
- 加仓、减仓及退出偏好。
- 事件前后是否限制新增风险。
- 预期失效条件。

目标价表达用户期待，不是系统预测或必然成交点。区分“到价提醒”“到价考虑减仓”和“到价提示全部退出”；达到目标时具体如何处理需明确，不能擅自推断。禁止建议自动当作成交入账。

### 第六步：通知与确认

选择提醒接收会话、收盘日报时间、盘中提醒与免打扰设置；可直接使用当前个人会话。界面只展示消息将发送到哪里，不出现共享组合、成员邀请或角色选择。若更换提醒会话，只需更新这一设置。

最后展示生效摘要：默认策略、风险参数、市场预期及期限、个股覆盖、当前缺失信息和对应能力范围。用户确认后设置生效；另用 `/盯盘 监控 开启` 明确订阅，不因开始或完成向导自动订阅。

## 4. 按需引导与交互状态

```text
未开始 → 收集草稿 → 待确认 → 已启用
             ↕
           已暂停

已启用 → 修改草稿 → 确认新版本 → 重新评估相关计划
```

用户未完成设置就查询行情：直接返回数据并给简短引导入口。用户请求个性化建议：只询问本次功能缺少的信息。默认模板已展示并经用户选择后，可避免重复填写其每个参数。

持久化一份个人引导状态，支持返回、跳过可选项、取消、恢复和超时暂停；分步消息只接受与当前步骤匹配的回答。配置页与聊天同时修改时使用设置版本校验，避免旧草稿覆盖新设置，不建立多用户会话管理模块。

完成配置后新增股票只询问该标的特有信息，不重跑整个向导。后台任务不自动启动多轮提问，只合并发送待完善项目的摘要及入口；记录提醒状态，避免刷屏。

自然语言优先用于降低输入负担，例如“这只准备拿半年，不想做短线”。能够明确映射为已有设置时直接保存并反馈解析结果及继承差异；有歧义的内容先澄清，未支持的条件明确标为备注，不能直接编译为任意代码或执行规则。

明确的设置指令可直接保存并返回结果，普通参数修改不强制重复确认。自然语言存在歧义时才追问；首次整体启用和重要变更用简短摘要让用户看清结果，避免把设置过程做成审批流程。

## 4.1 选择入口的位置

| 使用位置 | 呈现内容 |
| --- | --- |
| 安装/插件配置页 | 行情来源、凭证、模型及运行参数 |
| 首次使用 | 已有设置摘要，仅补齐缺失的投资偏好 |
| `/盯盘 设置` | 个人默认策略、风险、市场预期与通知设置 |
| 添加股票时 | 继承默认，或只为这只股票定制 |
| 个股分析报告 | 当前生效策略与预期的简短摘要，以及修改入口 |
| 预期到期/缺少必要数据时 | 一次合并提示，可更新、延后或保留观察模式 |

首版通过指令、分步聊天及宿主配置页提供入口，按钮或菜单按平台能力渐进增强，不依赖额外开发一套管理网站。

## 5. 用户预期与行情观察的关系

报告分别展示：

1. 用户假设：例如本周偏多，及设置时间和有效期。
2. 行情观察：由当前可用数据计算的事实与信号。
3. 策略行为：当前采用哪些规则、触发了什么约束。
4. 冲突说明：用户预期与观察不一致时，解释具体差异及需复核之处。

市场预期不能修改原始行情、伪装为模型预测、绕过可交易性或已确认风险上限。设置为“仅背景”时不直接调整确定性规则参数；AI 仍可基于证据质疑该假设，并明确说明独立判断及其与用户预期的差异。

当目标价、退出价、时间条件或风险限制冲突时，在保存时说明冲突并要求明确修正；不能只因为个股覆盖优先就接受逻辑矛盾。

## 6. 设置变更对计划的影响

策略、风险、大盘预期或个股目标变更后，仅重新评估受影响标的。将旧的待触发建议标记为被新设置替代，保存历史；重新计算后再启用新条件，避免旧条件在变更后继续通知。

设置变化不修改历史成交、已发送记录或过去分析。纯通知时间变更不需要重算交易策略。报告需说明本次动作变化主要来自行情变化还是设置变化。

## 7. 首版验收场景

- 首次使用未设置就查行情，能够查看并收到一次简短引导入口。
- 安装配置与聊天设置共用同一份个人档案，不出现管理员/普通用户分流。
- 添加股票默认归入个人组合，不要求选择所有者、成员或角色。
- 向导中断或插件重启后能够恢复草稿，未确认设置不会生效。
- 两只股票分别继承与覆盖持有周期，解析结果及来源正确。
- 关闭加仓不会被当成未填写，从而被默认值重新启用。
- 大盘偏多与行情转弱同时存在时，分别呈现，不篡改观点或行情。
- “仅作为背景”的市场预期不直接改变确定性规则参数，AI 的独立判断另行说明依据。
- 大盘预期到期停止应用，复核提醒去重。
- 缺少风险设置时保留观察能力，不生成缺少依据的个性化操作建议。
- 修改设置后旧触发条件失效，历史建议保持可追溯。
- 不支持的自然语言策略不会被误报为已经启用。
