# v0.2 默认规则与分项风险方法

本表是实现与验证的起点，不表示已经验证交易收益。规则版本 `daily-trend-0.2.0`、模板 `trend-v1.0`。个人的仓位、风险与回撤数值不在此代填。

| 项目 | 实现定义 |
| --- | --- |
| MA20/60 | 最近20/60根完整供应商日线收盘价的算术平均，使用统一调整口径 |
| ATR14 | 最近14个 true range 的算术平均，不宣称 Wilder 平滑 ATR |
| 年化波动 | 过去20个简单日收益的样本标准差乘 sqrt(252)，不是未来波动预测 |
| 量比 | 最后交易日成交量 / 此前20个交易日平均量；不是交易软件的盘中量比 |
| 趋势基线 | 收盘价 > MA20 > MA60 为 up，否则 weak；少于60日为 unknown |
| 相对表现 | 对齐最后21个共有交易日，计算个股与基准的20日涨幅差 |
| 价格口径 | 技术序列单独计算；将最后同一交易日原始价 / 调整价之比用于展示当前技术位置，不直接拿复权价与账面成本比较 |
| 短期风险等级 | 年化历史波动 >=50% 或 ATR/收盘 >=4% 为高；>=25% 或 >=2% 为中；更低为低；数据不足为未知。阈值属于待验证的启发式，不是损失概率 |
| 仓位风险 | 有完整组合估值及用户上限时，超上限为高，超过上限80%为中，否则低；缺失估值或上限为未知 |
| 事件/持有逻辑风险 | 由 AI 引用材料解释；未核实日历和证据时保持未知，不能因没有抓到新闻就称风险低 |
| 回撤基准 | 成本、持仓高点、近20日高点分别计算；期初持仓早期历史未知时，不声称知道完整持仓高点。完整买入周期的高点按登记日期以来日线最高价计算，包含买入当日成交前的可能高价，不等同于精确成交时刻以来高点 |
| 软与硬约束 | 复核型回撤只给提示；明确退出价/退出型阈值触及才构成硬退出优先项 |
| 到价处理 | 达到个人目标时，提醒/复核只给提示；显式减仓/退出偏好优先于模型动作，仍不自动下单或记成交 |
| 新增仓位 | 需风险参数、有效行情、完整现金和组合估值；已有持仓还需明确允许加仓；超限或关键缺失时不输出可直接采用的买入/加仓动作 |
| 股数上界 | 在允许新增风险且候选入场/退出价有效时，以单股额度、总仓位额度、记账现金及单次风险预算求最小值，向下取整股；按本次估值计算，未来到价需重算；未扣费用，不表示交收购买力或实际下单指令 |

未完成的供应商日线时段核实明确列为限制。上述指标只描述所获得的数据口径，不假称已经完成纯常规时段日线策略的实盘验证。
