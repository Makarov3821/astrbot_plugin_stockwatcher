## 真实宿主验收

1. 在目标 AstrBot 安装依赖并加载插件，确认帮助和状态指令能返回。
2. 用测试记录登记期初持仓和现金，记录其 ID；重载插件后核对持仓、关注和现金仍存在。
3. 测试买入、部分卖出和撤销；完成后按依赖顺序撤销测试记录，避免与个人账本混用。首次可使用单独的测试宿主。
4. 设置提醒目标，运行推送测试，人工核对消息是否真正送达。
5. 重载/卸载时发起查询，确认没有遗留任务和“数据库已关闭”写入错误。

## 真实行情验收

1. 通过宿主配置页或本地环境变量设置实际账户的 Alpaca 凭证；模拟/真实账户模式需对应。
2. 运行 `/盯盘 诊断 MU` 或 README 中的 CLI；保留脱敏诊断结果，不能将缺少凭证的 `not_verified` 当作通过。
3. 检查标的资料、日线、调整日线、常规分钟数据是否非空，查询截止是否超过免费延迟窗口。
4. 对照券商或其他可核实来源抽查 OHLCV、单位、交易日与复权事件。确认供应商日线具体包含的交易阶段后，才能提升其时段标记。
5. 覆盖普通交易日、节假日、提前收市日、夏令时切换样本；离线样例通过不代替真实历史数据抽查。
6. 连续运行观察空数据、限流及更新时间。服务可访问不等于长期稳定性已验证。

## 已知边界

- 本版只手动查询，没有自动日报、价格触发、策略评分、AI 或多智能体运行。
- 财务账本为加权平均记账，不是券商交收、融资或税务成本模拟。持仓数量不代表实际可卖数量。
- 同日事件以登记顺序排序，尚不接收盘中成交时间。现金余额快照覆盖之后的记账起点。
- 免费历史查询不能反映当前即时价格。供应商日线范围暂标记为未核实，不用于声称纯常规日线的策略。
- 元数据声明目标 AstrBot 范围 `>=4.28.2,<5`，目前接口核对依赖本地源码及官方文档，尚无真实宿主运行证据。
