# 按需深度研究与预算

`/盯盘 深度 MU` 获取一次证据快照，再由基本面、技术面、事件、多方、空方五个角色独立论证，最后一次汇总。`深度 MU 缓存` 可以研究已保存材料，但仍标为缓存观察，不能变成当前执行建议。

所有角色复用当前会话或指定的 AstrBot 模型，属于同一模型的不同研究视角，并非五家独立预测系统。角色看同一证据包、用户偏好、持仓和指标，不交换彼此初稿；汇总不把多方/空方票数变成概率。每个角色保留观察期限、支持论据与反证，时间范围不同的观点分别记录。

单轮最多 6 次模型调用，不自动追加辩论或重试，角色并发默认 2，总超时默认 300 秒，每次模型调用默认 90 秒。角色输出结构、引用和未经校准胜率经过检查；失败角色明确列出，有效角色继续汇总。v0.7.2 起，全部角色失败时不再额外调用单模型汇总，明确深度研究未完成并退回程序观察；有部分角色成功时可汇总，但报告开头明确未完整完成。汇总或总超时失败也退回程序观察，并保存已完成角色与失败信息。旧版保存的单模型备选仍可查看，但明确不是完整多角色结论。普通巡检和程序日报均不启动深度研究。

所有单模型、可选 AI 日报和深度研究共享数据库预算：默认每天 24 次调用、200000 个规划用 token。以展示时区日期重置；失败、取消及进程中断的预留也计入，避免重试绕过上限。v0.7.5起，深度开始前检查剩余6次调用和整轮预计预算：五个角色使用真实输入，汇总按截取后论据、引用与错误摘要的大小上界估算。预算不足不启动角色调用，报告保留需求及剩余估算。预检不预扣整轮预算，实际请求仍逐次原子预留，并行其他请求仍可能耗尽余额；不保证模型服务或输出一定成功。默认额度不会自动提高。

输入字符上限默认 24000，材料正文进一步截取，每篇最多 1600 字，超限省略篇目并记录覆盖。深度为给角色汇总预留空间，使用更小的同一证据包。角色完整论据持久化，汇总只接收每类最多两条、每条最多 200 字的摘要。查看历史报告可回看角色分歧及缺口，不能声称每篇长公告都已全文阅读。

`/盯盘 用量` 查看当天调用记录、预留预算和提供商可得用量。输入以 UTF-8 字节数保守估算，加请求的输出额度预留；不是精确 tokenizer 统计或实际费用上限。模型请求会传 `max_tokens`，不同 AstrBot 提供商对该参数和用量字段的支持需实测，不能据此保证账单。可在配置页调整预算，调用上限或预算为 0 时禁用模型，账本与规则监控仍可使用。

## 完成程度与报告的区别

普通分析只调用一次研究模型；深度研究通常为五个独立角色加一次汇总，所有角色复用同一模型和同一批材料。增加角色不会自动增加最新行情、财报或新闻，也不要求结论一定改变。目前仍无角色互相追问、反驳后再修订的多轮博弈。

深度简报首先区分“五角色与汇总均完成”“仅部分角色汇总”“汇总未完成”。每个成功角色展示中文角色名、观察期限、观点方向、主要论点和保留疑点；不再重复普通报告的整组均线与波动数字。缺失角色直接列出，失败归为预算、超时、引用或格式等类别，详情保留实际错误。不能将2/5成功仅因汇总格式合格就称作完整深度研究。

角色观点相近可能源于相同证据或同样缺少基本面资料；显示一致也比强行制造分歧更诚实。不同期限的多空观点不自动构成相互矛盾，更不能按角色人数算胜率。模型任务提示要求各角色回答自身研究角度，但真实研究增益仍需对照材料评估。

角色解析接受标准JSON代码块包装；仍严格检查角色代码、字段、引用和重复JSON键，不从额外解释文字中猜测修复结果。没有追加自动重试，单轮调用上限仍为6。

更新后可直接重看 `/盯盘 报告 3`，展示已保存的角色结果；`/盯盘 报告 3 详情` 显示完整论点、反证、引用及每个失败原因，不重新调用模型。

## v0.7.3 可追溯的引用失败

所有已返回角色的原文和元数据在校验前记录，失败也保留；角色与汇总的诊断记录出错字段和具体被拒绝引用，材料清单对应真正发给角色的裁剪后输入。只接受实际提供的字段路径与材料编号，允许精确字段引用不意味着接受未知新闻或语义正确性已经证明。历史编号表不再进入模型提示，数据库原始审计历史不删改。

`报告 ID 引用诊断` 是不调用模型的短视图。旧版本报告没有失败角色原文时明确说明无法还原，不能把已经被拒绝的技术面、事件和空方观点当成已经进入过汇总。

v0.7.4修复运行端报告#4暴露的数组下标兼容问题：`source_gaps[0]` 与 `source_gaps.0` 都可精确指向实际存在的第一个缺口，不再因方括号写法误拒绝整个角色。越界下标、非数组下标和不存在的字段仍拒绝，来源缺口仍不能代替真实事件材料。已有报告保留生成时的结果与诊断，不自动重新校验或调用汇总；更新后可新建一次深度研究，再查看新报告的引用诊断。

v0.7.5根据报告#5明确偏好实际值位于`preference.values`，例如`preference.values.horizon_days`；模型遗漏`values`仍拒绝，不自动将无效引用替换为猜测路径。若实际允许范围中存在对应路径，诊断可提示供核对，旧报告也可只读显示提示。提示不意味着该路径支持模型论点，更不使旧失败角色进入原汇总。
