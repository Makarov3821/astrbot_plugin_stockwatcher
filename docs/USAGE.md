# v0.5 设置和研判操作

先登记实际持仓和现金，或添加关注股票，再运行 `/盯盘 开始`。不依赖额外网站或成员权限配置。

## 分步设置

首次普通查询只显示一次引导入口。个人引导依次补充账户、策略/周期、风险、回撤、大盘预期和通知偏好；安装时已明确填写的项目跳过。`/盯盘 开始 MU` 仅补充这只股票缺少的目标/期限、理由、加仓偏好，其他字段继承个人设置。

当前回答方式为明确指令与 `键=值`，带空格的值使用引号；尚未用 AI 解析自然语言设置。命令不含隐式成交或自动订阅。

| 命令 | 含义 |
| --- | --- |
| `/盯盘 开始 [MU]` | 开始个人或个股引导，已有草稿时恢复；切换股票前先完成或取消 |
| `/盯盘 回答 ...` | 按当前提示回答，也可 `跳过`；策略/通知步骤可 `采用默认` |
| `/盯盘 引导 状态/暂停/继续/返回/取消/确认` | 管理持久化草稿；未确认不生效；超 24 小时的回答先暂停 |
| `/盯盘 设置` | 查看个人默认值和版本 |
| `/盯盘 设置 MU` | 查看个股生效值及每个字段的来源 |
| `/盯盘 设置 [MU] 字段=值 ...` | 直接修改并保存新版本；个股 `字段=继承` 删除覆盖 |

可配置字段：

| 字段 | 取值/含义 |
| --- | --- |
| 账户 | 现金/保证金/未知；不代表已验证交易权限 |
| 策略、周期 | 趋势；1～3650 天，默认 60；本版仅实现一个日线模板 |
| 允许加仓 | 是/否/未设置，未知不会被自动当成允许 |
| 单股上限、总仓位上限、单次风险 | 0～100 的百分数，不带 `%`；风险是入场到失效价的预算，不是亏损概率 |
| 回撤、基准、用途 | 阈值百分数；成本/持仓高点/近20日高点；复核/退出，三者应配套明确 |
| 目标、目标期限、到价 | 正价格、YYYY-MM-DD；提醒/复核/减仓/退出，默认复核 |
| 退出价 | 用户明确的正价格退出阈值，必须低于已设置目标 |
| 理由、复核目标 | 原有持有或关注逻辑；是否允许 AI 提出目标候选 |
| 日报 | HH:MM，按展示时区；另外开启监控和日报后才自动推送 |
| 公司页面 | 单个 HTTPS 公司 IR 页面，域名还需在配置的允许列表内 |

账户、总仓位上限和日报是个人字段，不提供个股覆盖。个股风险上限只能更严格，不能绕过已明确的个人限制；设为未设置也不能消除个人上限。缺少组合现金或任何持仓的同日估值时，不计算精确权重或新增资金上界。

`/盯盘 大盘预期 偏多/中性/偏空/暂不判断 期限=YYYY-MM-DD [基准=SPY 理由=...]` 以纽约日终为期限，过期停止应用，历史保留。本版仅作背景，不因看多放宽风险上限；尚不提供自动到期提醒。

## 证据与分析

`/盯盘 材料 更新 MU` 刷新 SEC、新闻和配置的 IR 页；`材料 列表 MU` 查看时点可用的来源。未设置 SEC 联系标识、新闻权限不足、接口异常都会展示缺口，不能解释为无新闻。

手工材料示例：

```text
/盯盘 材料 添加 MU 链接=https://example.com/release 标题=用户摘要 发布时间=2026-10-16T20:00:00Z 内容="自己整理的观察"
```

手工材料始终标为未经抓取核验的用户备注，不能冒充已核实 EPS。来源核验仅指数据来自指定接口或域名，不代表新闻中的传闻或观点已被证实。同一规范链接保留更正版本；删除追踪参数而保留有意义的查询参数。相同标题和正文的新闻转载只纳入一份，近似改写尚不做语义去重。撤回版本不会回退为旧的有效材料。只有公开且已经首次观察到的内容可进入相应时点报告。

`/盯盘 分析 MU` 获取原始和 all 调整日线、SPY 或指定基准、日历与材料，再调用一次 AstrBot 模型。`分析 MU 缓存` 不联网，不能作为当前执行建议。没有原始及调整快照则明确失败，绝不注入演示数据。

程序计算指标、风险预算和压力情景；模型解释持有逻辑、反证和回调候选。模型引用必须来自输入；目标价格由程序计算；候选入场价格关系、期限、仓位约束均经过检查。`validated` 表示通过上述结构和特定数值约束，**不证明引用与全部文字在语义上匹配，也不证明预测正确或收益可靠**。

模型输入材料正文每篇最多 1600 字，最多 15 篇，仍受总输入字符预算限制，提示中记录截断和省略数量；并非每篇全文阅读。数据库保存所抓取内容及本次证据包、实际提供的材料覆盖、行情快照、设置版本、提示版本、模型标识、可得用量和原始输出，不保存模型隐藏推理。报告对比上次参考价、材料版本和设置版本。

`分析记录 MU` 列最近 10 次，`报告 ID` 查看已有报告，过期报告会注明。相同平台消息重复投递只返回原报告；另发消息是一次新研判。生成期间设置或账本变化时保存为 `superseded`，不产生活跃目标候选；模型失败保存为 `degraded`，用户明确的退出条件仍可由有效行情触发程序观察。

`目标` 查看最近候选，`目标 采用 ID` 才更新个人目标和期限，`目标 拒绝 ID` 保留原目标。候选 7 天后、设置版本变化后不能直接采用。历史 EPS 仅支持情景，估值倍数由模型提出，尚无前瞻盈利预测和拆股后 EPS 专项核对；应结合原始财报审阅。

v0.5 已提供显式采用的条件计划、持续监控和日报，见 [监控说明](MONITORING.md)；按需多角色见 [深度研究](DEEP_RESEARCH.md)，首次安装及备份恢复见 [安装试用](INSTALL_TEST.md)。仍不支持自然语言改设置或订单执行。历史回撤、ATR、风险等级和压力情景不代表未来损失概率。
