# 自然语言聊天

v0.7.0 默认接管白名单中的专用私聊。长期偏好、数据来源和通知开关在插件设置页管理；会随行情和想法变化的大盘预期、关注与个股期待在聊天中记录。

## 查询与总览

“隐藏设置总览”“隐藏设置纵览”“聊天设置总览”会显示已经保存的大盘预期、持仓、关注池、个股覆盖、最近20条回调计划、最近10条AI目标候选、引导状态、当前入口的聊天修改草稿和监控状态。总览明确区分已保存记录与未确认草稿，不把不存在的信息补成默认看法。

“我现在的大盘走向判断是什么”只查已记录的大盘预期，不重新预测市场；显示方向、有效期、理由及是否过期。时间按展示时区输出。内部UTC时间、数据库字段、枚举和创建时间不作为确认内容展示。

常见查询直接走程序，不调用模型。其他自然表达由AstrBot模型识别；结果仍由已有查询函数读取并生成，模型不能自行声称数据库里有什么。

## 修改与补充信息

支持通过自然语言提出大盘预期、个股期待、关注池、提醒接收入口和监控/日报偏好的修改，也能登记已经存在的持仓、已发生的成交与现金记录。个人长期偏好优先去设置页管理；原有明确指令仍可修改并同步配置页。

复杂表达只识别为受支持的操作名与参数。模型不获得工具权限，不能生成任意可执行命令。缺信息时追问，不把“打算买”当作“已经成交”。保存最近三轮简短对话帮助补充期限和股票指代；仍建议一次只说一件事，除内置公司别名外提供美股代码。

修改先显示中文草稿；个股字段显示当前值与准备修改的值。回复“确认”才调用已有业务函数保存，回复“取消”放弃。每个入口只有一份当前修改草稿，提出另一项修改会替换旧草稿；普通查询不清除它。

草稿15分钟内有效，只能原入口确认。期间个人偏好、账本、关注池或监控状态变化时拒绝执行旧草稿。草稿和最近32条处理回执持久化，有平台消息ID时相同消息不重复处理；登记成交还复用账本幂等键。即使重启，也不会再次确认同一条已保存记录。

旧引导未结束时不创建另一份自然语言修改草稿；可完成或 `/盯盘 引导 取消`。显式重新开始引导会取消本入口之前的聊天修改草稿，避免“确认”同时指向两份内容。

## 当前范围

| 功能 | 入口 |
| --- | --- |
| 大盘预期、个股期待、关注、持仓与现金登记 | 自然语言草稿确认，或原有指令 |
| 普通分析、深度研究、行情查询 | 自然语言或原有指令；调用数据服务和模型时仍受预算与权限约束 |
| 提醒入口、监控、日报、AI日报、免打扰、自动保存候选 | 设置页、自然语言草稿或原有指令 |
| 长期投资偏好 | 优先设置页；原有明确指令仍支持 |
| 计划采用/取消、AI目标候选采用/拒绝、备份恢复、撤销历史账本、手工证据维护 | 本轮仍使用明确指令，见 USAGE.md |
| 自动下单、任意自定义策略、A股和港股 | 不支持 |

自然语言识别也计入每日模型预算。模型返回无效格式、字段不受支持、服务失败或预算不足时，不执行修改，提示换说法或使用明确指令。模型的真实理解准确率仍需在你的模型上测试；离线替身只能验证路由和校验逻辑。

关闭“由盯盘助理接管授权私聊”后，无关聊天恢复交给宿主，进行中的旧引导短回答仍可处理。白名单、私聊类型及主动发送校验不因独占聊天而放宽，其他插件已注册的指令也不被当作自然语言修改。

## v0.7.1 分析简报

分析保留用户原始问题进入研判，默认先展示简报。可以说“查看详细依据”“报告1详情”，或使用 `/盯盘 报告 1 详情` 展开完整材料和诊断，不增加模型调用；省略编号时读取本入口上次查询的报告，没有记录时明确说明。旧报告可以用新简报格式查看，但不会补造旧记录没有的年内指标。
