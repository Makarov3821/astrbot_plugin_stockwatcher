# StockWatcher 私人盯盘助理

给自己使用的 AstrBot 美股盯盘插件。记录已有持仓和关注股票，读取延迟行情与公司披露，借助 AstrBot 的模型分析持有逻辑、目标价和回调条件，并发送提醒或日报。不会自动买卖。

当前版本 **v0.7.5**。在你授权的私聊中，默认由插件接管普通消息，可以直接用自然语言交流。长期习惯在插件设置页填写，大盘看法、选股和个股目标在聊天中记录。

## 第一次安装，按这个顺序做

1. 在 AstrBot 的插件管理中，用仓库地址安装：`https://github.com/Makarov3821/astrbot_plugin_stockwatcher`。需要 Python 3.12+，AstrBot `>=4.28.2,<5`；建议先使用 4.29.1 或兼容更新版本。
2. **给机器人发私聊** `/盯盘 入口`。它会返回一段完整的会话标识，把整段复制下来。
3. 打开插件设置的 **「01 · 入口与聊天」**，在「消息入口白名单」添加刚才那段标识。至少一项，可以多个；只有这里列出的私聊能访问你的数据。
4. 在 **「02 · 行情与公告来源」** 填入 Alpaca API Key ID 和 Secret Key。没有凭证时仍可记录持仓和偏好，但无法查询真实行情。AI 使用 AstrBot 已配置的聊天模型，无需另填模型密钥。
5. 在 **「03 · 长期投资偏好」** 填你的长期习惯与风险限制。不确定的风险数字留空；不要填 0 来表示不知道。每项都有中文说明和选项。
6. 若需要主动提醒，在 **「04 · 提醒与日报」** 的接收入口粘贴同一段会话标识，再开启监控；需要日报时另开日报。先试用时可以全部保持关闭。
7. 保存设置并重载插件，在刚才的私聊发送 **“隐藏设置总览”**。能看到记录总览后，再用 `/盯盘 诊断 MU` 检查行情是否可用。

完整的逐项配置解释、Alpaca 凭证与投资账户的区别、试用步骤见 **[安装和设置指南](docs/INSTALL_TEST.md)**。

## 日常直接这样说

| 你说的话 | 助理会做什么 |
| --- | --- |
| 隐藏设置总览（也接受“纵览”） | 展示已保存的大盘预期、持仓、关注池、个股期待、提醒计划、AI目标候选、草稿与监控状态；未设置的也会说明 |
| 我现在的大盘走向判断是什么 | 只读取你已记录的大盘判断、有效期和理由，不让 AI 重新猜测 |
| 我的个人偏好是什么 | 查看当前真正生效的长期偏好 |
| 看看美光的个股设置 | 查看美光的生效设置，包括个人偏好继承后的值 |
| 我觉得美股到2026年底偏多，理由是…… | 理解后展示大盘预期草稿，确认后保存；缺少期限会追问 |
| 关注美光，理由是等待回调 | 展示关注草稿，确认后加入关注池 |
| 把美光的目标价改成1000美元 | 展示本次要改的字段及前后值，确认后保存；其他个股字段沿用原值 |
| 我已经持有MU 2股，每股成本100美元 | 展示期初持仓登记草稿，确认后记账，不扣现金、不买入 |
| 分析一下MU | 普通单模型简报：结论、行情依据、主要风险和缺口；保留你的具体问题用于研判 |
| 深度研究美光 | 五个角色独立分析后汇总，展示完成程度、各自期限、论点、疑点和缺失角色；尚无多轮交锋 |
| 查看详细依据／报告1详情 | 查看本入口上次报告或指定报告的完整依据、新闻链接和诊断，不重新调用模型 |
| 看看引用诊断／报告1引用诊断 | 只查看引用失败的位置和被拒绝的引用，不发送整份新闻清单 |
| 把提醒发到这里／开启监控／关闭日报 | 展示对应修改，确认后保存，并同步到插件设置页 |

示例数字只用于说明表达方式，不是交易或仓位建议。每次先说一件事；复杂表达依赖模型，遇到不明确的信息会追问。修改草稿在当前入口15分钟内可回复“确认”或“取消”；也能在“隐藏设置总览”中查看。普通查询直接读取记录，不要求确认。

常见查询不用模型。复杂意图识别、个股研判、多角色研究和 AI 日报共享模型预算；模型不可用时不会假称已执行，常见查询和明确指令仍可使用。基本公司别名包括美光、英伟达、苹果、微软、特斯拉、博通，其他股票建议直接提供美股代码。

分析默认不再铺开新闻列表、内部风控字段或长小数。若AI引用未通过校验，会明确说明没有形成有效结论；程序走势观察不能代替确认底部。需要完整记录时用 `/盯盘 报告 编号 详情`。

原有 `/盯盘` 和 `/stockwatch` 指令仍可用，见 [完整操作说明](docs/USAGE.md)。计划采用、目标候选采用/拒绝、备份和更正历史账本等操作，当前继续使用明确指令。其他插件已注册的命令仍优先放行。关闭「由盯盘助理接管授权私聊」后，恢复为明确指令与进行中的引导短回答。

## 设置保存在哪里

长期偏好、凭证、接收入口和通知开关在 AstrBot 插件设置中。通过聊天或原有指令修改的长期偏好、接收入口与通知开关，会同步回配置页；如果页面已打开，刷新查看。配置页改动需保存并重载。

持仓、关注、大盘预期、个股期待、分析历史和草稿保存在 `data/plugin_data/astrbot_plugin_stockwatcher/stockwatcher.sqlite3`。多个白名单入口共用同一份个人数据，待确认的聊天修改只接受原入口确认。

从旧版升级时，原配置自动归入新分组，账本和已保存的聊天记录保留。原来未完成的引导可用 `/盯盘 引导 继续` 恢复，确认页面已改为中文；也可 `/盯盘 引导 取消` 后直接使用新聊天方式。

## 行情和分析的范围

先支持美股。Alpaca 的 paper/live 选择的是数据凭证所属账户；paper 也读取真实市场行情。当前用免费 SIP 历史查询，默认预留16分钟延迟，日线只用已结束交易日，分钟只用完整常规时段。不是实时盯价，不能保证每次价格变化都被捕捉。

公告与材料来自 SEC EDGAR、允许域名中的公司 IR 页面及账户有权限访问的 Alpaca 新闻接口。SEC 需要填写含真实联系邮箱的请求标识；缺来源时会明确显示。AI 分析只使用收集到的材料和账户记录，不保证价格目标实现；目标调整候选由你采用后才生效。

风险预算、回撤和触发条件的含义见 [规则说明](docs/RULES.md)。监控、免打扰及日报机制见 [监控说明](docs/MONITORING.md)，多角色研究与预算见 [深度研究](docs/DEEP_RESEARCH.md)。
